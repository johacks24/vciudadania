# ADR-0003: Alcance histórico — solo legislatura XV

**Fecha:** 2026-11-10 · **Estado:** aceptada

**Contexto:** el Congreso ofrece datos desde la XIV (febrero 2020, ~8.700 votaciones
entre XIV y XV). Empezar por todo retrasa la validación y el producto.

**Decisión:** el primer lote de datos (01) cubre solo la legislatura XV (~2.200
votaciones del Pleno). La XIV es no-objetivo hasta que la XV esté navegable y validada.

**Consecuencias:** menos historial para el juego (04), pero ingesta y validación
abarcables. El modelo de datos no debe suponer «una legislatura» para no bloquear la XIV
después.
