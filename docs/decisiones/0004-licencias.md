# ADR-0004: Licencias — AGPL-3.0 (código) + CC BY-SA 4.0 (contenidos)

**Fecha:** 2026-11-10 · **Estado:** aceptada

**Contexto:** objetivo copyleft («que nadie cierre lo que es público»). Hay varios
copyleft: GPL, AGPL, LGPL, MPL para código; CC BY-SA y ODbL para datos/contenidos.

**Decisión:**
- Código: **AGPL-3.0** — copyleft real para webapps: si alguien sirve una versión
  modificada por internet, debe publicar su código.
- Contenidos y datos elaborados (resúmenes, fichas, normalizaciones): **CC BY-SA 4.0**.
- Los datos originales del Congreso y del BOE no son nuestros: se citan y se rigen por
  sus condiciones. Las fotos de diputados y otros elementos de terceros quedan fuera.

**Consecuencias:** máxima apertura garantizada hacia abajo (derivados siguen abiertos).
Alguna integración futura podrá exigir cuidado con dependencias incompatibles con AGPL.
